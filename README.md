# ⚡ ViralPulse AI — Advanced Video Virality & Retention Intelligence

ViralPulse AI is a modern SaaS platform designed to predict video virality, analyze second-by-second audience retention curves, diagnose hook quality, and generate algorithmic recommendations for **YouTube Shorts**, **Instagram Reels**, and **TikTok**.

---

## 🌟 Key Features

- **Multi-Modal Ingestion Suite**: Direct video upload (MP4/WebM/MOV) with in-browser video playback, social link parser (YouTube, TikTok, Reels), and detailed script creator studio.
- **6-Factor Virality Engine (0–100 Score)**: Evaluates Hook Strength (30%), Retention & Pacing (25%), Engagement Velocity & Shares (20%), Trend & Audio Synergy (10%), SEO & Hashtag Power (8%), and Optimal Posting Timing (7%).
- **Interactive Second-by-Second Retention Curve**: Dynamic SVG chart with drop-off risk flags and comparison against Top 1% Viral Benchmarks.
- **AI Hook Doctor Studio**: 5 proven copywriting formulas (Curiosity Gap, Contrarian Hot Take, High Stakes, Step-by-Step Blueprint, Shock Value) with real-time score recalculation.
- **A/B Head-to-Head Arena**: Test competing hooks or titles side-by-side with statistical win probability.
- **Retention & Pacing Lab**: Interactive timeline cue editor (B-roll jump cuts, text pops, sound effects) that dynamically updates watch-time predictions.
- **Competitor & Niche Intelligence**: Benchmarks across Business & Tech, Skincare & Beauty, Fitness, Finance, and Entertainment.
- **SEO & Hashtag Suite**: 3-tier hashtag stack (Broad Discovery, Niche Authority, Search SEO) and high-CTR title variations.
- **Export Scorecard**: Shareable report preview, clipboard summary, and JSON audit export.
- **Minimalist Dark/Light Mode**: Sleek obsidian and zinc theme with animated particle constellation canvas.

## 🚀 Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite 5
- **Routing**: React Router DOM v6
- **Styling**: Custom CSS Design System (Minimalist Linear/Vercel inspired, Glassmorphism, Responsive Grid)
- **Icons**: Lucide React + Custom SVG Platform Icons
- **Animation**: Canvas HTML5 Constellation Mesh + Canvas Confetti

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/muskanchoudhary1601-create/virality.git
cd virality
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
